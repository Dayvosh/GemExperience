# disclaimer-text.md

**Job:** Hold the exact, word-for-word safety disclaimer text. This is the only file the agent should ever copy this text from. It must never be reworded, shortened, or rewritten from memory of the PRD.

## Where it is shown
Once, as a mandatory checkbox at signup. It is not shown again anywhere else in the product.

## Exact text

"I understand GemExperience does not process payments, handle logistics, or resolve transaction disputes between users. If I list an outfit for rent, I am responsible for my own checks before handing it over, such as asking for identification and collecting payment first. If I rent an outfit, I understand GemExperience does not verify listings or guarantee an outfit's condition, and I am responsible for verifying details and arranging payment carefully, and meeting in a public place if meeting in person."

Reason this text cannot be paraphrased: it addresses both roles in one combined statement, since one account can act as either. A rewritten version could accidentally drop the rental-specific or renter-specific guidance, or weaken the legal and safety intent behind the exact wording.
